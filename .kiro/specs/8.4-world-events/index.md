# Spec 8.4: World Events

## Status: 📋 NOT STARTED

## Overview

Scheduled atmosphere changes, NPC schedules, and dynamic world state affecting all players.

## Roadmap Reference

See `docs/v1-roadmap.md` — Phase 8

## Estimate

125-175 credits

## Dependencies

- MVP Complete (Phase 6)
- World systems (5.4) for time/weather

## Scope Summary

- Scheduled weather changes affecting all players
- NPC schedule system (NPCs move between locations)
- Time-based world state changes
- Event notifications in World News
- Dynamic atmosphere based on world state

## Deliverables

- [ ] Weather changes on schedule (not just per-turn)
- [ ] NPCs move between locations based on time
- [ ] World events trigger at scheduled times
- [ ] Events appear in World News feed
- [ ] Atmosphere descriptions reflect world state
- [ ] At least 5 recurring world events at launch
