# Spec 8.5: Content Seeding

## Status: 📋 NOT STARTED

## Overview

Populate the world with NPCs, locations, location art, and codex entries. Foundation for rich gameplay.

## Roadmap Reference

See `docs/v1-roadmap.md` — Phase 8

## Estimate

175-250 credits

## Dependencies

- MVP Complete (Phase 6)
- Locations system working

## Scope Summary

**NPCs (50-100 characters)**
- Merchants, guards, flavor NPCs across all locations
- Rich personalities with rumors/leads
- Dialogue hints, relationship starting points

**Locations (Complete world)**
- All POIs with descriptions, connections, atmosphere
- Art/images for major locations (Supabase Storage)
- Discovery prerequisites and travel connections

**Codex Entries (Lore foundation)**
- World history, factions, notable events
- Item descriptions and origins
- Location backstories and legends

## Deliverables

- [ ] 50+ NPCs seeded across locations
- [ ] All major locations have descriptions
- [ ] Location art for 10+ key locations
- [ ] 30+ codex entries for lore
- [ ] NPCs have rumors/leads for organic storytelling
- [ ] Travel connections defined between all locations
