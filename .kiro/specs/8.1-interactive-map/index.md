# Spec 8.1: Interactive Map

## Status: 📋 NOT STARTED

## Overview

Visual world map with POI markers, travel UI, and location discovery. Core feature for world exploration.

## Roadmap Reference

See `docs/v1-roadmap.md` — Phase 8

## Estimate

150-200 credits

## Dependencies

- MVP Complete (Phase 6)
- Locations system working (5.4 world-systems)

## Scope Summary

- Visual map showing full world/region artwork
- POI markers appear once discovered in adventure
- Click discovered POI to see details, travel option
- Current location indicator
- Undiscovered POIs hidden (terrain still visible)
- Region boundaries and labels
- Travel time display between locations

## Deliverables

- [ ] World map renders with region artwork
- [ ] Discovered POIs show as clickable markers
- [ ] Undiscovered POIs hidden from map
- [ ] Current location clearly indicated
- [ ] Click POI shows details popover
- [ ] Travel option from map UI
- [ ] Travel time displayed between locations
