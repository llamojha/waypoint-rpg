# Spec 8.3: Character Customization

## Status: 📋 NOT STARTED

## Overview

Expanded portraits, cosmetic equipment, and character backgrounds for personalization.

## Roadmap Reference

See `docs/v1-roadmap.md` — Phase 8

## Estimate

100-150 credits

## Dependencies

- MVP Complete (Phase 6)
- Achievement system (8.2) for titles

## Scope Summary

- Expanded portrait selection (20+ options)
- Cosmetic equipment slots (no stat impact)
- Character background selection (flavor text)
- Title system from achievements
- Portrait unlocks from achievements

## Deliverables

- [ ] 20+ portrait options available
- [ ] Cosmetic slots separate from equipment
- [ ] Background selection during creation
- [ ] Titles display with character name
- [ ] Some portraits/cosmetics locked behind achievements
- [ ] Customization UI in character panel
