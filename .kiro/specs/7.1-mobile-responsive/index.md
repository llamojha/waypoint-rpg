# Spec 7.1: Mobile Responsive

## Status: 📋 NOT STARTED

## Overview

Make the UI touch-friendly and responsive across all screen sizes. Critical for mobile player experience.

## Roadmap Reference

See `docs/v1-roadmap.md` — Phase 7

## Estimate

150-200 credits

## Dependencies

- MVP Complete (Phase 6)

## Scope Summary

- Touch-friendly UI controls (larger tap targets)
- Responsive layout for all screen sizes
- Mobile-optimized input handling
- Swipe gestures for panel navigation
- Viewport and orientation handling

## Deliverables

- [ ] All UI elements have adequate touch targets (44px minimum)
- [ ] Layout adapts to mobile/tablet/desktop breakpoints
- [ ] Input field works well on mobile keyboards
- [ ] Panel navigation works via swipe or tabs on mobile
- [ ] No horizontal scroll on any viewport size
- [ ] Mobile usability score > 85%
