# Generated Content

This directory contains JSON files generated by the content-generator agent.

Files are named by type:
- `npc-<name>.json`
- `location-<name>.json`
- `quest-<title>.json`
- `codex-<title>.json`
- `news-<title>.json`

To seed content to Supabase:
```bash
npx tsx scripts/seed-content.ts --dry-run  # Preview
npx tsx scripts/seed-content.ts            # Insert all
```
